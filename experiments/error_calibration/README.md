# Discretization-error estimator: calibration probe

Feasibility probe. Is gradwave's single-shot plane-wave (Ecut) error estimate (`postscf/discretization_error.py`) truthful enough across chemistry that a small model calibrates its bias away, and how large is the (ecut, k-mesh) cross term the additive error budget ignores? Research-notes register; see `docs/ideas.md` "Error estimation: the rest of the budget".

Method: per system, one converged reference cutoff `ecut_ref`; three loose cutoffs at 0.50 / 0.65 / 0.80 of it. The FFT density grid is fixed to the reference grid for every run, so only the plane-wave orbital sphere changes (what the estimator addresses). `ecut_large = ecut_ref`, so the estimator annulus and the truth window are the same interval. Truth = `E_total(ecut_ref) - E_total(ecut_loose)`, same k-mesh, same grid, PBE, norm-conserving ONCV pseudos. All values eV unless noted. Generated by `analyze.py` from `results.json`.

## 2. Calibration (leave-one-system-out)

Correction fit on the log-ratio `L = log(true/est)`; the calibrated estimate is `est * exp(prediction)`. Skill is the RMS of `L` before calibration vs the RMS of the held-out residual after. `L` RMS of the raw estimate is the baseline (a perfect estimator has L=0).

| model | params | in-sample | LOSO held-out RMS(L) | vs raw |
|---|---|---|---|---|
| raw estimate (no calib) | 0 | 0.1633 | 0.1633 | 1.00x |
| (a) global scale | 1 | -- | 0.0817 | 0.50x |
| (c) linear [frac] | 2 | -- | 0.0367 | 0.22x |
| (c) linear [gap, frac] | 3 | -- | 0.0419 | 0.26x |

Global scale factor (in-sample geomean of est/true) = 0.867: the raw estimate on average captures 87% of the true error; the one-parameter calibration multiplies est by 1/0.867 = 1.153.

In natural terms RMS(L) maps to a typical multiplicative miss of exp(RMS): raw 1.177x (about 18%), global scale 1.085x (9%), linear [frac] 1.037x (4%). Adding the gap descriptor does not beat [frac] alone out-of-sample (0.0419 vs 0.0367); six systems support the ecut-fraction slope but not a chemistry descriptor.

In-sample linear [gap, frac] R^2 = 0.849, coefficients [b0, b_gap, b_frac] = [0.532, 0.0006, -0.602].

(b) Per-element scale is untestable out-of-sample here: every system is a distinct element set, so leave-one-system-out removes that element's only data and per-element degenerates to the global mean for the held-out point. Reported as not supported by N=6 distinct systems, not as a negative result.

## 4. Findings and verdict

1. The estimator is a consistent under-estimate: all 18 ratios lie in [0.75, 0.98], never above 1. This matches its construction (first order at fixed density, diagonal kinetic denominator): it captures the complement channel and misses part of the self-consistent relaxation.
2. The bias is systematic, not scatter. Within every system the ratio rises monotonically toward 1 as ecut approaches the reference, and the per-system geomeans agree to within a few percent (0.83 to 0.89 across insulators, semiconductors, and metals).
3. Calibration works out-of-sample. A single global scale halves the log-ratio RMS on held-out systems; a two-parameter model on the ecut fraction cuts it to about a fifth (typical held-out miss about 4%). The band gap adds nothing at N=6; per-element scales are untestable at N=6 (each element appears in one system).
4. The (ecut, k) coupling is second order for the total but first order for the k line item at very loose cutoffs. Budget totals are safe to add; per-axis attributions are not, below about 0.65 of the converged cutoff.

Verdict: GO for a small calibration layer. The signal is a smooth, monotone, chemistry-insensitive function of the ecut fraction, exactly what a tiny model (or even a fixed 1-2 parameter correction shipped with the estimator) can remove. The active-learning loop is worth one more probe at larger N before committing: extend to about 20 systems (delta-gauge elements give geometry plus pseudos for free), check whether per-element structure emerges beyond the frac slope, and only then decide between a fixed correction and a learned one. Caveats: N=6, cubic 1-2 atom cells, NC ONCV pseudos, PBE, energy channel only; force/stress ratio behavior not measured here.
